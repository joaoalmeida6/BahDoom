# BahDoom Engine

Uma engine inspirada no Doom, desenvolvida do zero em C como um projeto de aprendizado e experimentação com desenvolvimento de engines, arquitetura de computadores e multiplayer.

O objetivo é construir uma engine moderna, modular e bem documentada, mantendo a filosofia e os formatos que tornaram o ecossistema Doom tão extensível.

### Principais objetivos

* 🎮 Suporte a **tela dividida** para multiplayer local.
* 🌐 Multiplayer funcional, com foco em cooperação e partidas online.
* 📦 Suporte a padrões de compatibilidade estabelecidos pela comunidade, como **MBF21** e **ID24**.
* 🧩 Arquitetura modular e extensível.
* 🔧 Ferramentas para análise e validação de WADs.
* 📚 Documentação clara sobre a arquitetura da engine e suas especificações.
* ⚙️ Código escrito em **C**, priorizando aprendizado, controle e compreensão de cada parte do sistema.

O projeto ainda está em estágio inicial. A ideia não é apenas criar mais um source port, mas aprender como uma engine de jogos funciona construindo cada camada gradualmente — desde o game loop e gerenciamento de memória até renderização, carregamento de WADs e networking.
