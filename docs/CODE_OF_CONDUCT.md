# Code of Conduct

## Our Pledge

We are committed to making participation in the BahDoom project a welcoming, respectful, and constructive experience for everyone.

Contributors are expected to communicate professionally, treat each other with respect, and focus on improving the project regardless of experience level, background, or role.

## Expected Behavior

Examples of behavior that contribute to a positive environment include:

- Being respectful and considerate toward other contributors.
- Welcoming newcomers and helping them understand the project.
- Giving and receiving constructive feedback.
- Discussing technical disagreements objectively and in good faith.
- Respecting different approaches, opinions, and levels of experience.
- Keeping discussions focused on the project and its goals.
- Providing useful context when reporting bugs, proposing changes, or reviewing code.
- Giving appropriate credit to contributors and external projects when applicable.

## Technical Discussions

BahDoom is a software project, and technical disagreements are expected.

Healthy disagreement is encouraged when it helps improve the engine. Contributors may challenge design decisions, implementations, or technical proposals, but criticism should be directed toward the idea or implementation rather than the person.

For example:

**Constructive:**

> "I don't think this approach fits the engine architecture because it couples the renderer to the game layer. Could we consider keeping this interface in the core instead?"

**Not constructive:**

> "This is a terrible implementation. You clearly don't understand engine development."

Strong technical opinions are welcome. Personal attacks are not.

## Unacceptable Behavior

The following behavior is not acceptable:

- Harassment, discrimination, or personal attacks.
- Trolling, deliberate provocation, or persistent bad-faith arguments.
- Insulting or belittling other contributors.
- Threats or intimidation.
- Publishing someone's private information without permission.
- Sexual harassment or unwelcome sexual attention.
- Deliberate disruption of project discussions or development.
- Repeatedly ignoring reasonable requests from project maintainers.
- Any other behavior that would reasonably be considered inappropriate or harmful in a professional open source community.

## Scope

This Code of Conduct applies to:

- GitHub issues.
- Pull requests.
- Code reviews.
- Discussions.
- Project documentation.
- Community communication related to BahDoom.
- Other spaces when an individual is representing the BahDoom project.

## Reporting Issues

If you experience or witness unacceptable behavior, please report it to the BahDoom project maintainers.

Reports should include as much relevant information as possible, such as:

- What happened.
- When and where it happened.
- The people involved.
- Links to relevant issues, pull requests, comments, or other material.
- Any additional context that may help the maintainers understand the situation.

Reports will be handled as respectfully and confidentially as reasonably possible.

## Enforcement

Project maintainers are responsible for interpreting and enforcing this Code of Conduct.

Depending on the severity and circumstances of a violation, maintainers may take actions including:

1. Asking the contributor to stop the behavior.
2. Removing or editing inappropriate content.
3. Issuing a warning.
4. Temporarily restricting participation in the project.
5. Removing a contributor from the project or community.
6. Reporting serious incidents to the appropriate authorities when necessary.

Enforcement decisions will be made based on the circumstances of each case.

## Good-Faith Contributions

Mistakes are part of software development.

Not every disagreement, incorrect implementation, poorly written comment, or failed contribution constitutes a violation of this Code of Conduct.

Contributors are encouraged to assume good faith, ask for clarification, and resolve misunderstandings constructively whenever possible.

## Maintainer Responsibilities

Project maintainers are expected to:

- Lead by example.
- Apply this Code of Conduct consistently.
- Treat reports seriously.
- Avoid conflicts of interest when handling reports.
- Keep enforcement focused on maintaining a healthy development environment.
- Explain moderation decisions when doing so is appropriate.

## Attribution

This Code of Conduct was written for the BahDoom project and is inspired by common practices used by open source communities.

The BahDoom project may update this document as the community and project evolve.
